# Round Robin CPU Scheduling

## Project Overview
This project implements the Round Robin CPU Scheduling algorithm, a preemptive scheduling technique used by operating systems to allocate CPU time fairly among processes.

## Objectives
- Implement the Round Robin CPU Scheduling algorithm in C.
- Simulate process execution using a configurable time quantum.
- Calculate completion time, turnaround time, and waiting time.
- Display the execution sequence using a Gantt chart.
- Calculate average turnaround time and average waiting time.

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Environment:** Linux / WSL

## Project Structure
- `Source-Code/` – C source code for the scheduling algorithm.
- `Documentation/` – Project report and documentation.
- `Review-PPTs/` – Project review presentations.
- `Screenshots/` – Program execution output screenshots.
- `Other-Files/` – Additional project resources, if applicable.

## How to Compile and Run

Navigate to the directory containing `round_robin.c` and execute:

```bash
gcc round_robin.c -o round_robin
./round_robin
```

Enter the process details and time quantum when prompted.

## Output
The program displays the Gantt chart, process scheduling metrics, average turnaround time, and average waiting time.
